ShopSimpleWpf

Это простое приложение для работы с таблицей товаров.

Файлы:
- LoginWindow - окно выбора роли.
- MainWindow - главное окно и кнопки.
- Database - запросы к базе данных.
- App.config - подключение к SQL Server.
- Database.sql - создание базы данных.

Роли:
- Администратор видит кнопки и может менять данные.
- Пользователь может только смотреть таблицу.

Кнопки:
- Добавить - создает новый товар.
- Изменить - изменяет выбранный товар.
- Удалить - удаляет выбранный товар.
